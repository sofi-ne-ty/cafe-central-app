# Café Central – Aplicación web de pedidos

# Nombre del proyecto
cafe-central-app

# Descripción
Este proyecto consiste en crear una aplicación web para que los clientes de Café Central puedan consultar el menú, revisar los precios y realizar pedidos desde una computadora o un celular.

# Problema que resuelve
Busca facilitar los pedidos y permitir que los clientes conozcan los productos y sus precios sin tener que preguntar directamente en la cafetería.

# Funcionalidades principales
- Consultar el menú.
- Visualizar los precios.
- Registrar clientes.
- Seleccionar productos.
- Crear pedidos.
- Consultar el estado de los pedidos.
